## 做了什么

使用scikit-learn内置的[UCI Wine真实测量数据](https://archive.ics.uci.edu/dataset/109/wine)：178条、13个特征、3个类别。固定分层划分124条训练、54条验证，random_state=42；StandardScaler只在训练集拟合。没有伪造数据或预填指标，没有GPU/云计算。

该历史验收当时沿公司EPT配置使用`andes-glm-5.x-auto`，不切换账号、模型或计费来源。真实模型自行选择第一项候选：标准化逻辑回归，C=1。操作者核对方案并通过正式Research.review批准最多两次单线程CPU拟合，每次至多30秒；Research.run实际执行训练、保存收据、指标和54条预测，正式证据接口完成回收。

| 真实结果 | 数值 |
| --- | --- |
| 正确样本 | 53 / 54 |
| 验证准确率 | 98.1481% |
| 验证macro-F1 | 0.982861 |
| 三类召回率 | 100%、95.2381%、100% |
| 正式运行完整入口耗时 | 3.156秒；拟合与预测约0.015秒 |

固定小验证集并非独立测试集，不能由这个分数推断工业性能、统计显著性或普遍泛化。此任务是传统分类模型，不是深度神经网络/GPU验收。

## 没有通过什么

将基线指标交回同一原生线程后，下一实验建议未在110秒内完整返回。明确中断并只读核对原turn为interrupted后，操作者仅做了一次缩短要求的续接；90秒内仍未完成，随后中断并核对。共请求3个原生turn：1完成、2中断；turn数不是模型API调用次数。第二次拟合未执行，剩余额度未消耗。停止后只核验已有证据，保存操作者结束评审，未用手工候选把流程补成成功。

110/90秒是这份验收驱动的等待上限，不是产品常规超时设置。该事实说明本次有界接续没有完成，不能仅凭它确定EPT服务、模型、线程恢复或产品程序中哪一项是根因；后续应沿原收据定位，不盲目重发。
