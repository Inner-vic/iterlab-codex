# 接续、消息操作与 Skills

## 执行位置与准备工作

制定方案时应核对代码入口、数据是否可达、依赖和资源，再明确选择本地、开发空间或组件库。需要上传数据、交互调试时优先考虑开发空间；入口和数据稳定、需要批量排队时可选组件库。公开数据不必然属于某一种执行方式。

项目“运行”页可以明确选择后续训练位置。这个选择独立保存，不改写历史审核，也不新增 GPU 或预算授权。选择开发空间后，旧组件库提案不能继续准备或提交；没有 SSH 时显示具体环境缺口，后台等待，不反复唤醒模型请求重新授权。已提交任务仍按原身份监控和回收，不因改地点取消。

保存并验证 SSH 后，仍核对新地点的具体方案、空间身份与资源。旧组件库授权不会冒充开发空间授权。复制同一公开数据并校验哈希属于数据传输，不能与换数据来源、标签或评价划分混为一谈；如果用户确实固定了不可迁移的数据位置或私有数据范围，则尊重该具体约束。

开发空间执行器支持明确文件清单的流式快照上传与远端逐文件 SHA-256 校验，输入范围调整为 2 GiB，本地短运行仍为 512 MiB。更大数据需独立传输/可复核的远端数据入口，不能静默改回本地或组件库。当前并未实现跨实验共用数据缓存和任意大数据上传；没有实网 SSH 连接时不能宣称训练或传输通过。

## 面向用户的消息和名称

项目和会话名称使用同一种应用内编辑弹窗，不展示宿主绝对路径。修改名称不移动文件、不更换原生线程。后台交接只显示一句阶段进展，例如“正在独立评审方案和已有证据”或“正在核对本轮执行情况，整理结果并分析下一步”；角色合同、兼容工具格式和内部 ID 不进入该提示。

显示层通过原投递身份、确切原生轮次和已保存的合同识别自动输入回显，兼容只读收尾在角色合同前附加指令的历史消息；不按关键词删除人类引用，不修改原始消息、事件或执行合同。

## 统一运行页和研究画布

工作区保留脉络、实验、文件、运行四项。运行页合并原环境配置和运行记录：配置默认折叠，明确缺 SSH 时展开。只在选择开发空间时显示空间绑定及 SSH；本地和组件库不展示 SSH。旧代码中的 execution 导航兼容映射到运行页。项目运行汇总本项目各会话提交或明确绑定的运行，不扫描全平台；同一实际组件任务去重，通知偏好仍作用于原所属会话。会话顶部摘要只展示该会话任务。

脉络的历史浏览提示保持两行以内，摘要按需展开；聚焦/完整范围并入图内顶部工具栏，搁置和参考关系作为图内底部图标开关。缩放、拖动、点击空白取消选择及原有证据关系保持。图谱与文件的放大窗共享尺寸和固定标题栏；文件放大后使用目录/内容双栏。

模型连接页只提供 CLI 通道、规划模型与执行模型。前台不再设置推理强度，保存时使用模型默认；未保存前不改变已有设置。目录请求包括分页及隐藏项，不根据私有/付费标签在前端筛选。连接返回的目录不等于计费权限；目录缺失模型不应伪装成可用。当前机器实测 EPT 配置 private_models_only=false，但其实际 model_catalog.json 与完整 model/list 仍均仅含两个私有模型；这项上游目录缺口尚未解决。未替换账号、修改全局配置或试用付费模型来伪证可用。

## 系统暂停与用户停止

系统因无进展暂停后，旧方案与收尾报告保持关闭。后台只登记一次恢复审议，投递到原会话；有实际改动的修复后继须由当前 Critic 对确切正文和证据独立批准，再通过原授权核验采纳。累计不清零，未知投递/计算、待决平台操作、证据缺口及审批仍阻断。首次自主授权包含该策略；旧项目须显式登记，历史只读验收不会因升级自动重开。没有可行修复时停下，不反复唤醒。

用户主动停止、归档、移除、关闭自主模式或撤销授权不走系统恢复。普通消息可以恢复对话，不能替代新的训练授权。停止 Codex 对话不取消已经提交的云任务。

`lifecycle.allowed_actions` 仅表示界面导航；`working` 表示原生轮次正在工作，不撤销训练授权。`execution_authorization` 表达具体方案授权；`agent_roles.role_routing_grants_execution=false` 表示角色交接不创造新权限。真正执行仍须后端实时检查角色、未知任务、冻结证据、位置、GPU及累计资源。

## 消息与会话

- **立即引导**：未发送的人类排队消息沿原身份引导当前轮次，没有活动轮次时优先处理。不另建重复消息。
- **删除排队**：仅取消未发出的本机排队项。
- **移除提示**：隐藏明确拒绝的提示，保留拒绝原件。未知状态不能隐藏或当作失败重发。
- **重命名会话**：会话行菜单可改名称，保持原项目、线程、消息和实验身份，检测多页面并发修改。

## Skills

`/` 菜单支持上下键选择、Enter确认、Escape关闭，输入法组合期间不抢占Enter。`/compact`压缩原生会话，`/skills`管理方法，`/mcp`查看原生连接。

`/skills` 列出当前CLI根据项目目录发现的条目。全局Skills沿用使用者已有CLI配置，不复制开发者账号目录。界面可导入本机已有Skill目录或SKILL.md绝对路径，安装位置为：

```text
<项目工作目录>/.agents/skills/<name>/SKILL.md
```

默认托管工作目录位于 `.data/workspaces/<project-id>/`。导入不覆盖同名副本、不热改活动轮次；需要合法name/description，不接收链接或常见私钥/凭据文件。当前单次最多512文件、50MiB。点击“使用”将 `$skill-name` 插入输入框，补充任务后发送，由Codex按需加载。查看或安装本身不提交训练。

“停用项目副本”移入本机 `disabled-skills` 归档，不删除全局或平台固定方法。此版支持本机目录导入、发现、使用和停用，不包含任意Git仓库下载、市场登录或自动升级。列出Skill不代表其专业任务已经验收。

## 读取失败

模型目录使用独立只读进程，和研究执行连接分离。缓存60秒，连接异常最多重试一次；显示旧缓存时标明状态，不把目录当作模型权限验证。LPAI/GitLab检查分别保留工具、SDK、认证与网络结果，仅网络/超时类瞬时读取可重试一次；代理错误、404、认证或权限问题需要针对性处理。这些读取逻辑不重试研究消息或云任务提交。

## LPAI执行与研究接续恢复（2026年11月5日）

- 正式提交先持久保存原请求身份，再调用官方SDK。回执落盘前进程退出可能留下`requested`；后台现在和`unknown`一样按原标记、平台身份及时间范围只读查回。活跃SDK提交持有同一锁，后台不会并发核对或重发；找不到唯一匹配就保留未知，不创建替代任务。
- 旧账号、失效绑定或已移除项目的恢复请求单独退避，避免占满有界批次、拖住后续任务。补监控失败与云提交分开，修复观察者不增加训练次数。
- 产物读取明确完成、子进程已清理且属于网络超时/网络不可达/429或临时服务错误时，共用原任务的三次回收上限，持久退避60/180秒；只读任务状态查询在传输前超时也可恢复。认证、权限、身份/边界错误、传输结果未知或清理未确认不自动重放。缺文件及网络恢复均不重训、不重置累计。
- 原生`research_status.round_evidence`中的云任务给出确切已关联分析记录和后继实验依据，区分尚未分析与已分析；不凭正文提到UID或标题相似猜关联。记录存在不等于结论正确，仍须读原件、按固定协议核对，并由Codex决定保留参数路线还是修订上层方案。
- 能力声明已对齐代码：小型训练产物回收、组件训练、受控开发空间SSH执行已实现；大权重自动下载、开发空间断线自动恢复仍未实现。声明不探测平台、不调用模型，也不把安装/配置或工程测试当成实网训练通过。

## 归档、移除与永久删除

| 操作 | 当前行为 |
|---|---|
| 归档聊天 | 隐藏常用列表，保留线程与记录，暂停自动推进；可恢复 |
| 移除项目 | 从侧栏移除，保留目录、聊天、实验、产物；可恢复，恢复不自动执行 |
| 永久删除本地记录 | 已提供入口：点击项目/会话删除可直接选择，也可从回收站操作。输入“确认”或“确定”后，实际删除该对象的数据库记录及关联索引，不能从回收站恢复；不删除工作目录文件、Codex原生历史、已有备份或云端资源 |

归档是收纳，回收站是可恢复删除，永久删除本地记录是真正删除数据库记录，三者不同。执行中、状态未知或其他会话仍引用这些记录时会拦截，失败会回滚。不要手工删SQLite行或删除整个 `.data` 来清理单个项目。

目前永久删除的范围是本地记录，尚不包含项目工作目录文件的清理，也不保证SQLite文件立即缩小；这不是完整的磁盘清理或安全擦除。若目的是释放模型、数据集、产物占用的磁盘空间，还需单独处理应用自有目录及备份。用户外部源码目录、官方Codex原线程和云平台资源属于独立范围，不能顺带删除。
