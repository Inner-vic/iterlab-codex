# IterLab 实验图表统一展示规范

版本：2026-10-31 · 实施前规范。**本轮只制定展示契约，不接入新实验数据、不实现结果图，也不提供虚构指标。** 图谱表示研究记录关系，实验图表表示数据；两者不得互相充当证据。

## 1. 一张图首先回答一个问题

| 数据任务 | 推荐形式 | 必须说明 |
|---|---|---|
| 训练随进度变化 | 线图，训练与验证使用独立身份/线型 | 横轴是 step、epoch 还是真实时间，纵轴指标和单位 |
| 少量方案比较 | 点图；确需表达绝对大小时用条形图 | 基线、相同评估条件、方向、重复次数 |
| 运行间波动与分布 | 原始点＋区间；箱线图适用于足够样本 | 点的含义、n、箱体/须规则、区间统计方法 |
| 多工况/类别比较 | 小多图或有限矩阵热图 | 相同尺度、缺失编码、类别排序与样本数 |
| 一个独立读数 | 简洁数值＋单位＋来源 | 单次还是聚合，不为一个值强行造图 |
| 不可比较或尚无证据 | 状态说明与证据入口 | 为什么不可比较；不画占位零值 |

不使用双纵轴、3D、彩虹色阶或装饰面积。不同单位/不同尺度拆图；指数化必须明确共同基准。不要将记录时间误作训练进度。

## 2. 每张图的固定骨架

**标题 → 比较条件 → 绘图区 → 图例/必要直接标签 → 统计与限制脚注 → 原始数据表/证据入口。** 条件与筛选在图上方一行，空间不足时折叠次级条件，不把关键评估条件藏进悬停。

- 标题15–16px、600；指标值使用等宽数字；轴/图例/脚注12px，主要说明13px。文字使用正文/次级文字token，不跟随系列颜色。
- 卡片内边距16–20px；标题与条件间6px；绘图区与脚注间12px。侧栏优先提供摘要与放大入口，完整分析放在放大视图，不挤压成不可读缩略图。
- 网格弱于数据，保留少量主刻度；横纵轴标签与单位不截断。自动布局须为负号、长类别和极端值留边距。
- 默认2px线、至少8px可辨点；相邻填充之间2px表面间隔，重叠点增加2px表面环；条形仅远离基线的数据端4px圆角，不能两端圆角模糊基线。
- 两个及以上系列必须图例；不超过4个系列时增加必要直接标签。单系列由标题命名，不再放重复图例框。

## 3. 结果解释与比较边界

| 字段 | 展示要求 |
|---|---|
| metric | 人可读名称与稳定key，不能只给缩写而无解释 |
| unit | 百分比、秒、毫秒、样本等；无单位明确标注，不把0–1直接当百分数 |
| direction | 越高越好 / 越低越好 / 目标区间 / 仅观察，不默认所有指标都越高越好 |
| baseline | 确切方案、运行、协议和数据版本；基线用清晰标签/虚线，不靠灰色猜身份 |
| comparison | 仅同划分、协议、样本范围、预算口径与聚合口径可比较；不可比项明确说明 |
| provenance | 原运行/结果ID、证据路径或原事件、产物回收状态、原记录时间 |
| statistic | 单次值 / 均值 / 中位数；运行次数n、样本数及独立单位，不能混用 |
| uncertainty | SD、SE、置信区间、分位区间等必须命名；方法与置信水平写脚注 |

不能将平台成功终态解释成结果已回收、评估已完成或研究目标达标。只有确切评审记录确认目标核验，才使用目标达标措辞；图上颜色不能独立判定。

差值先显示绝对变化；百分比指标的绝对差用“百分点”。相对变化必须注明分母与公式 `(new-baseline)/abs(baseline)`，基线为0时不计算相对百分比。小差值不使用红绿大字夸大，不因四舍五入后的差异宣称改进。

## 4. 轴、缺失与不确定性

- 条形/面积以零为基线；确需查看局部小差异使用点图或线图，并清楚显示轴范围。对数轴必须标注，不能隐藏零/负数的不可定义性。
- 比较图统一尺度；缩放与筛选不悄悄改变比较结论。数据降采样必须标注方法与原点数，原始数据表仍可到达。
- 缺失用“未记录/未回收/不适用”与断线、空单元或纹理表达，不能补零、插值冒充观测，也不能把不同实验首尾连成一条训练曲线。
- 误差条只来自可追溯统计；单次运行不能伪造置信区间，n太小明确限制。置信区间不是样本分布，也不等同新实验结果落入区间的概率。
- 独立单位应与实验设计一致：设备分组不能以窗口数冒充独立设备数；相同seed/相同设备的配对比较保留配对关系。

## 5. 色彩、身份与主题

当前规范采用小系列上限，色彩沿实体身份固定，不按指标排名或筛选后的位置重排，不循环复用。状态色与类别颜色是不同角色；标记颜色相近时以线型/点形/标签补强，不能把绿系列叫“已通过”。

| 固定slot | 浅色表面 `#ffffff` | 深色表面 `#282930` | 非颜色编码 |
|---|---|---|---|
| 1 · 蓝 | `#2a78d6` | `#3987e5` | 实线 / 圆点 |
| 2 · 橙 | `#eb6834` | `#d95926` | 虚线 / 方点 |
| 3 · 青绿 | `#1baf7a` | `#199e70` | 点划线 / 三角点 |

此三slot由dataviz脚本在**all-pairs**模式分别验证：浅色最小protan/deutan ΔE 9.2、正常视觉24.0；深色9.4/20.9。浅色青绿标记对比度2.82低于3:1，**必须可见标签与数据表，并保留不同点形/线型**；不能用于无辅助编码的细小独立标记。深色tritan模拟最小4.0，故线型/点形不可省略。验证只覆盖上述表面及3种颜色，不等同完整无障碍通过。

超过3个同时可比较系列时采用小多图，保留实体标签与共同尺度；不要默认生成第四色。确需更大色谱必须重新验证相邻/全配对与实际表面，并有纹理/标签，不沿用这次通过结论。

连续大小使用单色由浅到深色阶；正负变化使用冷/暖两端＋中性灰中点，明确中点的业务含义。纹理版/高对比/打印模式可用45°与135°斜纹及不同线型，不能仅翻转颜色。

## 6. 交互与可访问性

线图提供十字准线和悬停信息，点/条/热图按标记提供提示，命中区域大于标记本身。信息包括实体、横轴值、指标值/单位、统计定义、n与来源；缺失明确显示，不给伪造值。

同一信息键盘可达、焦点可见；Esc关闭提示/放大面板并合理返回触发控件。筛选不改变颜色身份，原数据表有可读列名、单位、排序口径与导出入口。触摸不作为当前电脑验收门槛，但不能以悬停作为唯一信息入口。

普通后台同步不自动改变用户缩放、展开、选中实验或键盘焦点；状态更新与数值更新分开。引用确切ID和会话选择版本，迟到数据不能覆盖另一个实验。

## 7. 后续实现的数据契约

契约必须包含 `metric.key/label/unit/direction`、`series.id/label/style_slot`、`points.x/y/status`、`statistic.kind/n/independent_unit/interval`、`comparison.protocol_digest/split_id/dataset_revision/baseline_ref`、`source.run_id/result_id/evidence_refs/collected_at`。未提供的字段保持null或明确状态，不能以空字符串/0消除不确定性。

前端只格式化与可视化，不默默重新评估结果或补算无来源统计；统计如需计算，应保存方法与输入来源。数据表展示原值、格式化值和适用单位，不为美观改写科学协议。查看图表不会自动启动实验、恢复未知请求或扩大权限。

## 8. 实施验收清单

实际接图后必须用同数据验证：浅深色、极端/负值/缺失/单次/多运行、长中文、筛选系列身份、共同尺度、近似小差值、原证据跳转、键盘及Esc、后台更新焦点/viewport、显示与表格一致。类别色重新运行脚本；截图检查碰撞、溢出、图例和标记几何。**本文件不代表上述真实实验图表已实现或通过验收。**
