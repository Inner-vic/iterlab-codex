# IterLab 品牌使用规范：B「生长」

2026-11-01，用户选定 B「生长」。本规范替代 2026-10-31 的循环双箭头校准说明。

## 身份与品牌语言

- 图形为开放 i/L 笔势：独立起点和舒展的连续曲线，不以叶片、星形、无限或刷新箭头代替。
- 品牌拼写为 **IterLab**。字标采用已批准的人文斜体矢量轮廓，不是可安装字体；正文、按钮和研究记录仍沿用原字体。
- 中文 slogan：**让好奇，长出新知。**
- 英文 slogan：**Let curiosity unfold.** 中英独立表达，不要求逐字翻译。
- slogan 仅放在首次项目欢迎页和无内容会话的欢迎场景；有内容的研究会话不叠加宣传文字。

## 同源文件

`static/brand-mark.svg` 是图形母版，72×64 单位；`static/brand-wordmark.svg` 是固定字标母版。`static/brand.js` 导出同一份矢量与品牌文案，初始化挂载到首页品牌位置，供会话欢迎场景复用。模块不访问模型、后台或浏览器存储。

SVG favicon 使用 40×40 深绿色 #1e3932 底座，原标志置于 34×34 的居中区域，白色反白。ICO 从这份 SVG 生成 16／32／48／64px 四尺寸，不能单独改绘近似形状。修改母版时必须同步模块、SVG favicon 与 ICO 并运行 `tests/test_branding.py`。

## 界面尺寸与颜色

- 展开侧栏：37×34px 标志，约128px宽字标，间距9px；品牌行保留原65px高度。
- 折叠侧栏：34×34px标志，隐藏字标。76px项目导航宽度、项目签、当前项与会话切换面板不变。
- 欢迎页：50×52px标志，最大280px宽字标；品牌句30px，较小桌面27px。
- 浅色图形 #2b5148，字标使用既有正文 `--ink`；深色图形 #d4e9e2，字标跟随正文反白。
- 中文品牌句用人文衬线，仅限该句。字体回退为 Noto Serif CJK SC / Songti SC / SimSun / serif；不联网下载。不同系统具体中文字形可能略有差异，英文字标固定为矢量，不受系统字体影响。
- 不拉伸、不裁切字腔、不加渐变、发光或持续旋转；Logo 不承担研究成功、失败或运行状态的语义。

## 本轮检查与边界

已检查同一母版路径及椭圆属性、固定七字母矢量、静态SVG安全、两个欢迎场景一致文案、多尺寸ICO目录、浅深色与三种电脑视口。真实隔离浏览器的已有导航／原请求保护回归通过。

本轮没有启停正式服务。运行中服务保持启动时静态快照，启用磁盘新版需在安全时机明确重启，再打开原地址。Windows实机的中文字体与浏览器页签视觉未直接验收；未做商标检索或可注册性保证。
